# 🌸 Iris Flower Prediction using Naive Bayes

This project is a **Machine Learning web application** that predicts the species of an Iris flower using a **Gaussian Naive Bayes classifier**.  
The model is deployed as a **live web app using Streamlit Community Cloud**.

---

## 🚀 Live Demo
🔗 https://iris-naive-bayes-app-todhvpzybzzbkj35pjn4dj.streamlit.app/

---

## 📌 Project Overview
- **Algorithm**: Gaussian Naive Bayes  
- **Dataset**: Iris Dataset (scikit-learn)  
- **Framework**: Streamlit  
- **Language**: Python  
- **Deployment**: Streamlit Community Cloud
